# Ouroboros

> เรื่องเบื้องลึกที่ไม่มีใครรู้ แม้แต่ตัวระบบเอง จนกว่าจะถึงเวลา

LLM เขียนเรื่องไปข้างหน้าทีละเทิร์น ไม่มีที่เก็บแผนไว้ใช้ทีหลัง เรื่องจึงลากไปเรื่อย ๆ ปมที่ปูไว้ไม่ถูกเก็บ Ouroboros ทำหน้าที่เป็นผู้เขียนลับอยู่เบื้องหลัง:

- **เก็บปม** หลังบอทตอบทุกครั้ง จดสิ่งที่เรื่องปูไว้แล้วยังค้าง (ของ คน ความลับ คำสัญญา คำถาม สถานที่ ปมในใจ)
- **วางชะตาลับหลายทางพร้อมกัน** (ชะตา A B C) แต่ละทางคือคำตอบว่าจริง ๆ แล้วเกิดอะไรขึ้น หักมุมแบบไหน จบอย่างไร
- **ตัดและล็อก** ชะตาที่ขัดกับเรื่องจริงถูกตัด พอถึงจุดที่กำหนด ชะตาที่เข้ากับเรื่องที่สุดกลายเป็นความจริง หักมุมจึงเข้ากับปมที่ปูไว้เสมอ และเดายาก เพราะก่อนล็อกแม้แต่ระบบเองก็ยังไม่ได้เลือก
- **ส่งให้โมเดลที่เขียนเรื่องแค่ที่จำเป็น** ช่วงของเรื่อง จังหวะถัดไป ปมที่ควรหยิบ และความลับที่ห้ามเผย ไม่ส่งแผนทั้งหมด
- **วงงูกินหาง** ช่วงไคลแมกซ์จะหยิบปมจากช่วงปูเรื่องกลับมา ตอนจบจึงวนกลับมาหาตอนต้น

คุณเห็นแค่ตัวเลข ไม่เห็นเนื้อหา เว้นแต่จะแอบดูเอง

## เริ่มใช้

1. Extensions → Ouroboros → เลือกโมเดลของ **ผู้เก็บปม** และ **ผู้ทอชะตา** (ข้ามได้ ค่าเริ่มต้นใช้ API หลักของ ST)
2. เปิดแชท แล้วเปิดแผงจาก **ปุ่มลอย** เมนู ไม้กายสิทธิ์ → **Ouroboros** หรือพิมพ์ `/ouro`
3. เลือกขนาดแผน (และอารมณ์ โจทย์ โทรป ถ้าอยาก) แล้วกด **เริ่ม**
4. คุยต่อตามปกติ ระบบทำงานเบื้องหลังเอง

## ขนาดแผน

| ขนาด | ความยาวประมาณ | ชะตาพร้อมกัน | ล็อกความจริงที่ |
|---|---|---|---|
| สั้น | 40–80 ข้อความ | 2 | ~50% |
| กลาง | 100–200 ข้อความ | 3 | ~60% |
| ยาว | 250–500 ข้อความ แบ่ง 3 องก์ | 3 (เรื่องหลัก) + 2 ต่อองก์ | องก์ ~60% · เรื่องหลัก ~70% |
| มหากาพย์ | ไม่จำกัด องก์ละ ~150 ข้อความ | 3 (เรื่องหลัก) + 2 ต่อองก์ | องก์ ~60% · เรื่องหลักเมื่อกด **เข้าสู่บทสุดท้าย** |

ช่วงเรื่อง: ปูเรื่อง → ไต่ระดับ → จุดเปลี่ยน → วิกฤต → ไคลแมกซ์ → คลี่คลาย ผู้ทอชะตาเลื่อนเร็วหรือช้ากว่ากำหนดได้นิดหน่อยถ้าเนื้อเรื่องยังไม่พร้อม ถึงความยาวที่วางไว้แล้วไม่บังคับจบ แผงจะถามว่าจะ **ปิดเรื่อง** หรือ **เริ่มภาคใหม่** (ปมที่ยังค้างตามไปด้วย)

## ใช้กับแชทที่เล่นไปแล้ว

ได้ ไม่ต้องเริ่มแชทใหม่ ตอนกดเริ่มมีสองตัวเลือก:

- **นับรวมข้อความที่มีอยู่แล้ว** ติ๊ก = ข้อความเก่าเป็นส่วนหนึ่งของความยาวเรื่อง · ไม่ติ๊ก = เริ่มนับจากตอนนี้ (แชทยาวควรเอาติ๊กออก ไม่อย่างนั้นเรื่องอาจเลยเป้าไปแล้วตั้งแต่ต้น)
- **เก็บปมย้อนหลัง** (ติ๊กไว้ให้แล้ว) ผู้เก็บปมอ่านแชทเก่าแล้วเก็บปมที่ยังค้างมาให้ ปมเหล่านี้นับเป็นปมช่วงปูเรื่อง จึงถูกหยิบกลับมาตอนไคลแมกซ์ได้ตามกฎวงงูกินหาง
  - ช่วงที่ **Memory Hub** สรุปไว้แล้ว อ่านจากสรุป (ถูกมาก ส่วนใหญ่ 1–2 ครั้ง) อ่านข้อความจริงเฉพาะช่วงที่ยังไม่มีสรุป
  - ไม่มี Memory Hub: อ่านข้อความเป็นช่วง ๆ ไม่เกิน 20 ครั้ง แชทยาวมากจะอ่านเฉพาะช่วงหลัง
  - ก่อนกดจะบอกว่าจะอ่านอะไรและใช้กี่ครั้ง ได้ปมไม่เกิน 15 ข้อต่อรอบ
  - ลืมติ๊กตอนเริ่มก็กดทีหลังได้ในแท็บ **ปม**

## กันนิสัยของโมเดล

โมเดลแต่ละตัวมีนิสัย บางตัวธงเขียวจัด ชอบทำให้ทุกทางนุ่มแล้วรีบคลี่คลาย บางตัวกำแพงศีลธรรมสูง ไม่ยอมเขียนเรื่องมืด Ouroboros มีที่กันไว้:

| | |
|---|---|
| **ความเข้มของเรื่อง** | นุ่มนวล · สมจริง (ค่าเริ่มต้น) · มืดหม่น เลือกตอนเริ่ม เปลี่ยนได้ในหน้าหลัก ระดับสมจริงขึ้นไปห้ามชะตาจบแบบ "ที่แท้เข้าใจผิดกัน" หรือ "ทุกคนดีหมด" ชัยชนะต้องมีราคา มืดหม่นต้องมีชะตาที่สูญเสียจริงอย่างน้อยหนึ่งทาง เป็นการกำหนดแนวเรื่องแต่ง ไม่ได้ช่วยหลบกฎความปลอดภัยของโมเดล |
| **โทนของชะตา** | โค้ดเป็นคนกำหนดว่าชะตาแต่ละทางต้องเป็นโทนไหน (สดใส · ขมหวาน · มืด) ตามความเข้ม ถ้าโมเดลส่งกลับมาโทนเดียวกันหมด ระบบให้เขียนใหม่ 1 ครั้ง ชะตาที่เกิดใหม่แทนทางที่ถูกตัดจะได้โทนที่ขาดไป |
| **กันรีบคลี่คลาย** | บันทึกลับก่อนไคลแมกซ์บอกโมเดลที่เขียนเรื่องว่าอย่าคลี่คลายความขัดแย้งหลัก ให้ปัญหาค้างไว้และมีราคา และผู้ทอชะตาถูกสั่งว่า ถ้าเรื่องคลี่คลายง่ายเกินไป อย่าตัดชะตาที่มืดทิ้งเพราะเหตุนั้น ให้หาราคาที่ต้องจ่ายแทน |
| **ห้ามเร่งเรื่อง** | สวิตช์ใน Extensions → Ouroboros ผู้ทอชะตาชะลอจังหวะได้อย่างเดียว |
| **API สำรอง** | ตั้งสำรองได้ทั้งผู้เก็บปมและผู้ทอชะตา ถ้าโมเดลหลักปฏิเสธ (จับคำตอบแนว "I can't help with that" ได้) หรือตอบว่าง จะข้ามไปตัวสำรองทันที ไม่ลองซ้ำกับตัวที่ปฏิเสธ |

## แผง

| แท็บ | |
|---|---|
| **หน้าหลัก** | วงงูกินหางบอกช่วงเรื่อง จำนวนปม จำนวนชะตาที่ยังเป็นไปได้ อารมณ์ (มีผลกับคะแนนชะตา) ปุ่ม **ทอชะตาตอนนี้** · **ตัดด้าย** (ทิ้งชะตาที่ยังไม่ล็อกแล้วเขียนใหม่ ไม่ต้องรู้ว่าทางเดิมคืออะไร) · **ขอปิดเรื่อง** / **เข้าสู่บทสุดท้าย** · เปลี่ยนขนาดแผน |
| **ปม** | ปมที่เปิดอยู่และที่เฉลยแล้ว แก้ ลบ หรือเพิ่มเองได้ ปมที่เพิ่มเองมีน้ำหนักมากกว่าปกติ |
| **ชะตา** | แอบดูทีละขั้น: **กลิ่น** (คำเดียวบอกธีม) → **เงา** (หนึ่งประโยคคลุมเครือ) → **เปิดหมด** ต้องแตะสองครั้งทุกครั้ง ดูแล้วหน้าหลักจะขึ้นว่า "แอบดูแล้ว" |
| **คลัง** | ชะตาที่ไม่ได้เกิด: ถูกตัดตอนไหน เพราะอะไร ปมไหนกลายเป็นปมหลอก และไปที่ข้อความที่เรื่องแยกทางได้ ถ้าเรื่องยังไม่จบต้องกดยืนยันก่อน เพราะการรู้ว่าอะไร "ไม่จริง" ก็ใบ้ได้ว่าความจริงเหลือทางไหน |

## swipe ลบข้อความ แตกกิ่ง

- ปมผูกกับข้อความและ swipe ที่เจอ swipe ไปทางอื่น ปมของ swipe เดิมพักไว้ swipe กลับมาก็กลับมา
- ปมที่เฉลยใน swipe ที่ถูกปัดทิ้ง กลับไปเป็นปมที่ยังเปิดอยู่
- ลบข้อความ ปมของข้อความนั้นหายตาม
- แตกกิ่ง / checkpoint: แผนตามไปด้วย ตัดปมที่อยู่หลังจุดแตกกิ่งออก
- ย้อนแชทไปก่อนจุดที่ล็อกชะตา: หน้าหลักจะมีปุ่ม **ปลดล็อกชะตา**

## ตั้งค่า (Extensions → Ouroboros)

| | |
|---|---|
| ผู้เก็บปม | ทำทุกครั้งที่บอทตอบ ใช้โมเดลถูกและเร็วได้ |
| ผู้ทอชะตา | ทำทุก N ข้อความของบอท เมื่อเปลี่ยนช่วงเรื่อง ถึงจุดล็อก หรือกดเอง ควรใช้โมเดลเก่งที่สุดที่มี |
| ทอชะตาทุก | 0 = ตามขนาดแผน (สั้น 6 · กลาง 8 · ยาว 10 · มหากาพย์ 12) |
| ขั้นสูง | ความลึกที่แทรกบันทึกลับ (ค่าเริ่มต้น 3) · ส่งในนาม · ปริมาณเนื้อเรื่องที่ส่งให้ผู้ทอชะตา · แม่แบบบันทึกลับ |

เลือกโมเดลได้จาก **Connection Profile** ของ ST งานเบื้องหลังไม่สลับ API ของแชทที่ใช้อยู่

## สมุดความลับ (หลังล็อกชะตา)

พอชะตาถูกล็อก ผู้ทอชะตาเขียนสมุดความลับทันที: ความจริง 1–3 ข้อ แต่ละข้อมี

- **ซ่อนจากใคร** รายชื่อตัวละคร (และผู้อ่าน) ที่ยังไม่รู้
- **จะเผยเมื่อไหร่** และ **เผยแล้วอะไรเปลี่ยน**
- **ไอเดียเบาะแส** เรื่องเล็ก ๆ ที่ชี้ไปหาความจริงแต่ตีความเป็นอย่างอื่นได้

แล้วผู้เก็บปมคอยจดในการเรียกเดิมทุกครั้งที่บอทตอบ (ไม่เสีย API เพิ่ม): **เบาะแสที่วางแล้ว** · **ใครรู้แล้ว** · **เผยแล้วหรือยัง** บันทึกเหล่านี้ผูกกับข้อความและ swipe เหมือนปม swipe ทิ้งก็หายตาม

บันทึกลับที่ส่งให้โมเดลที่เขียนเรื่องจึงบอกได้ว่า ความจริงข้อไหนยังต้องซ่อน ใครยังไม่รู้ (เล่น dramatic irony ได้) เบาะแสที่วางไปแล้ว และไอเดียเบาะแสถัดไป ข้อที่ถึงเวลาเผยจะบอกว่าเผยเมื่อไหร่ ข้อที่เผยแล้วจะเตือนให้เล่นผลที่ตามมาต่ออีกราว 40 ข้อความ ไม่ทิ้งไปเฉย ๆ และมีกฎว่า **ถ้าผู้เล่นไปถึงที่ที่ความจริงซ่อนอยู่ ต้องได้เจอ** ปกป้องความลับด้วยการทำให้ไปถึงยาก ไม่ใช่ด้วยการกั๊ก

ดูสมุดความลับได้ในแท็บ **ชะตา** หลังแอบดูชะตาที่ล็อกจนถึงขั้น **เปิดหมด** หน้าหลักแสดงแค่จำนวน (ความลับ n ข้อ · เผยแล้ว m)

## ใช้คู่กับ Megumin Suite

Megumin มีระบบความลับของตัวเอง (The Notebook) ถ้าใช้คู่กับ Ouroboros ในแชทเดียวกัน คำสั่งเรื่องความลับจะซ้อนกัน แนะนำ:

- ปิด **The Notebook** ของ Megumin (ถ้าใช้ preset V11 ให้ลบบรรทัดที่พูดถึง notebook ใน Dev Mode ด้วย ตามที่ Megumin เตือน)
- ปิด **Chomusuke** ในส่วนของ notebook ถ้าไม่ได้ใช้ทำอย่างอื่น
- World State, NPC Bank และระบบอื่นของ Megumin ใช้ต่อได้ตามปกติ

## ความลับรั่ว

ถ้าผู้เก็บปมเห็นว่าข้อความล่าสุดเผยความลับที่ยังไม่ถึงเวลา (ยังไม่ถึงไคลแมกซ์ของชั้นนั้น) (ใบ้หรือปูไว้ไม่นับ) ทำในการเรียกเดียวกับการเก็บปม จึงไม่เสีย API เพิ่ม ตั้งได้ใน Extensions → Ouroboros → **ความลับรั่ว**

| ตัวเลือก | |
|---|---|
| เตือน (ค่าเริ่มต้น) | ขึ้นคำเตือน แตะเพื่อ swipe ใหม่ คำเตือนไม่บอกว่าความลับคืออะไร |
| swipe ใหม่เอง | swipe ใหม่ให้ทันที ครั้งเดียวต่อข้อความ ถ้ายังรั่วอีกจะเตือนแทน |
| ไม่ตรวจ | |

## ต่อเรื่องในแชทใหม่

กด **เริ่มแชทใหม่ต่อเรื่อง** ใน Memory Hub แล้วแผนของตอนก่อนตามมาเอง: ความยาวเรื่องนับต่อ ปมที่ยังค้างตามมา ชะตาที่ล็อกแล้วยังล็อกอยู่ ถ้าไม่อยากให้ตาม กด **หยุดใช้ในแชทนี้** ในแชทใหม่ แผนจะไม่ตามเข้ามาอีก

## กันสปอยล์โดยไม่ตั้งใจ

- toast และรายงานตรวจปัญหาไม่มีเนื้อหาของแผน
- บันทึกลับไม่ถูกส่งตอน extension อื่นสั่งโมเดลเบื้องหลัง (เช่น ตอน Memory Hub สรุปความจำ)
- บันทึกลับมีเนื้อหาของแผน ถ้าเปิด prompt inspector ของ ST จะเห็น ถ้าไม่อยากโดนสปอยล์อย่าเปิดดู
- โมเดลที่แสดงส่วนคิด (`<think>`) อาจคิดถึงบันทึกลับในนั้น ให้ซ่อนส่วนคิดไว้

## เชื่อมกับ extension อื่น

- **Memory Hub**: ผู้ทอชะตาอ่านสรุปความจำของแชท เรื่องที่หลุดจาก context ไปแล้วจึงยังถูกนับ
- **As you command**: ใช้ด้วยกันได้ OOC ไม่ปนเข้างานเบื้องหลังของ Ouroboros

## ค่าใช้จ่ายและโมเดล

| งาน | เรียกบ่อยแค่ไหน | ต่อครั้ง (ประมาณ) | โมเดลที่พอ |
|---|---|---|---|
| ผู้เก็บปม (+ ตรวจความลับรั่ว) | ทุกข้อความของบอท (รวบหลายข้อความที่มาติดกันเป็นครั้งเดียว) | เข้า 1–2k · ออก 100–300 token | ถูกและเร็วได้ เป็นงานดึงข้อมูล |
| ผู้ทอชะตา | ทุก N ข้อความของบอท + ตอนเปลี่ยนช่วงเรื่อง ล็อก ขึ้นองก์ใหม่ หรือกดเอง | เข้า 5–9k · ออก 1–2.5k token | ระดับกลางขึ้นไป ยิ่งเก่งหักมุมยิ่งเนียน |

ขนาดกลาง 100 ข้อความของบอท ≈ ผู้เก็บปม ~100 ครั้ง + ผู้ทอชะตา ~15 ครั้ง (รวม ~300k token เข้า ~50k ออก) ทำไม่สำเร็จจะลองใหม่ 1 ครั้ง ดูจำนวนที่ใช้จริงวันนี้ได้ใน Extensions → Ouroboros

ถ้าผู้ทอชะตาเป็นโมเดลที่คิดก่อนตอบ (reasoning) ส่วนคิดอาจนับรวมในโควต้าคำตอบ ให้เพิ่ม **คำตอบผู้ทอชะตาสูงสุด** ในขั้นสูง (เช่น 8000) ไม่อย่างนั้นอาจได้คำตอบว่างหรือ JSON ขาด

## คำสั่ง

| คำสั่ง | |
|---|---|
| `/ouro` | เปิดแผง |
| `/ouro-weave` | ให้ผู้ทอชะตาทำงานตอนนี้ |
| `/ouro-debug` | ตรวจปัญหาแล้วคืนรายงาน (ไม่มีเนื้อหาของแผน) |

เปิดไม่ขึ้นบนมือถือ: Extensions → Ouroboros → **ตรวจปัญหา** แล้วคัดลอกรายงานส่งให้คนแก้ อัปเดตแล้วยังเป็นเวอร์ชันเก่า: กด **โหลดเวอร์ชันล่าสุด**

## ข้อจำกัด

- แชทกลุ่มรองรับแบบพื้นฐาน: บันทึกลับเหมือนกันทุกสมาชิก
- ตัวตรวจความลับรั่วใช้วิจารณญาณของโมเดล อาจพลาดหรือเตือนเกินได้
- ปุ่มลอยยังแต่งหน้าตาไม่ได้ (ขนาดและไอคอนตายตัว)
